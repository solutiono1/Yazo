How it works

Four steps. Nobody has to trust anybody.

Each one is enforced by the Lightning network itself. Not by a dashboard. Not by us.

1

Order

Pick an amount and who it's for. Yazo issues a Lightning hold invoice for that exact sum.

2

Pay

You pay the invoice. The network holds the payment. Not spent. Not released. Just held.

3

Show the code

The recipient gets a one-time code. It only gets shown once the goods are actually in hand.

4

Released

The code unlocks the hold. The vendor is paid in seconds. No waiting. No middleman.

The guarantee

Even we can't take it early.

A Lightning hold invoice only pays out to whoever can produce its preimage. Yazo derives that from a secret that only the recipient holds, and never stores it.

  • ✓ The vendor: never sees the recipient's secret
  • ✓ Yazo's servers: store only a salt and a payment hash, never the secret or the preimage
  • ✓ Whoever steals the entire database: same reason
  • ✓ Nobody, if it's never delivered: the hold expires and the payer is refunded automatically

Questions

Before you ask

What happens if the item never arrives?
The hold expires automatically (six hours by default), and the payment returns to the sender. Nobody has to ask for a refund; a watcher does it on its own.
Can the vendor take the money before delivery?
No. The payment only releases when the recipient's code unlocks it. The vendor never has that code until the recipient chooses to show it.
What if the code gets lost?
QR codes carry 128 bits of randomness, so there's no realistic way to guess one. If it's genuinely lost, the hold still expires on schedule and the money returns to the sender.
Is this real money?
Not yet. This build runs on Lightning's test network for the hackathon. The escrow logic is real and runs against a live two-node network; the funds moving through it are test funds.
Why Lightning, and not a stablecoin on another chain?
Lightning has a primitive most chains don't: a payment that can be held, then either released or returned, enforced by the network itself. Not by Yazo. Not by an admin button.
